# C++ Mini Projects

A collection of beginner C++ projects built while learning programming fundamentals, problem solving, and basic software design.

## Projects Included

### 1. Banking System

A simple console-based banking application that simulates basic ATM functionality.

#### Features

* PIN-based authentication
* Maximum of 3 login attempts
* Balance inquiry
* Money withdrawal
* Money deposit
* Input validation for deposits and withdrawals
* Menu-driven interface

#### Initial Settings

* Default PIN: `1234`
* Initial Balance: `100 Rs`

#### Concepts Used

* Loops
* Conditional statements
* User input handling
* Variables and arithmetic operations

---

### 2. To-Do List

A simple task management application.

#### Features

* Add tasks
* View all tasks
* Remove tasks
* Supports up to 10 tasks

#### Rules

* Maximum capacity: 10 tasks
* Tasks can be removed using their task number
* Empty task slots are displayed when viewing tasks

#### Concepts Used

* Arrays
* Strings
* Loops
* Menu-driven programs

---

### 3. Quiz Game

A multiple-choice quiz application.

#### Features

* Four quiz questions
* Automatic score calculation
* Percentage score display
* Case-insensitive answer checking

#### Concepts Used

* Arrays
* Nested arrays
* Loops
* Conditional statements
* Character manipulation

---

### 4. Credit Card Validator

A credit card validation program based on the Luhn Algorithm.

#### Features

* Accepts card numbers as input
* Validates card numbers using checksum calculations
* Displays whether the card number is valid or invalid

#### Algorithm Used

* Luhn Algorithm

#### Concepts Used

* Functions
* String processing
* Loops
* Mathematical operations

---

### 5. Rock Paper Scissors

A console-based implementation of the classic game.

#### Features

* Play against the computer
* Randomized computer choices
* Automatic winner determination

#### Rules

* Rock beats Scissors
* Scissors beats Paper
* Paper beats Rock
* Same choices result in a tie

#### Controls

* `r` → Rock
* `p` → Paper
* `s` → Scissors

#### Concepts Used

* Functions
* Random number generation
* Conditional statements
* User input handling
